RELEASE NOTES

What’s new in 2026.1

A redesigned Scratchpad, a more useful flow builder, a new Mac menu bar picker and optional on-device AI.

A more useful scratchpad

Start with Paste Text or Try an Example, then search formats and saved flows. Favourites and recently used transformations appear near the top. Result cards have visible Copy and Preview actions, with Share, Use as Input and favourite controls in their menus.

Preview the complete selectable result, then use it as your next input to chain transformations. Paste, Clear and Use as Input can be undone and redone alongside typing.

The workspace adapts to your window: input and results sit side by side when space permits, with a stacked layout for compact screens. Text and selection stay in the same editor when resizing or folding. Conversions run in the background, with safeguards for large input and expanding flows.

Build and inspect flows

The flow builder now shows live input and output. Choose Final Output to inspect the result after any of the first 100 steps. Numbered steps have switches so you can try a flow without an operation, then re-enable it later. Disabled steps keep their settings and stay disabled in saved flows.

Previewing does not save the flow or change your clipboard. Copy Preview is always an explicit action.

Start with a flow template

Try five recipes for pasted text, headlines, lists, URL slugs and Markdown quotes. Change the example input and copy the result straight away, or create an editable flow to keep and customize. Templates are available offline and never change your existing flows.

Scratchpad previews now have a compact Back button beside search. Input and output fields share consistent rounded corners.

Safer flows and better text handling

Flows now use coordinated atomic saves, a rolling backup and explicit recovery. Import and export portable flow backups from the Flows screen. Failed saves retain your edits, and unreadable originals are preserved during recovery.

Sentence casing, Unicode fonts and line-based formats handle more edge cases correctly, including Windows line endings. Personal dictionaries also apply to Sentence Case.

Open a .textcaseflow file from Files or Finder and confirm the import, or drag it onto the Flows list to add an editable copy.

Mac and command-line workflows

A native menu bar helper transforms clipboard text with favourite formats and saved flows. Its local snapshot remains available without waiting for iCloud. The command-line tool supports direct or piped UTF-8 text. Existing macOS Services names are retained.

Appearance

Scratchpad panels and controls follow Text Case's light/dark palette. Category colours remain visible, secondary text has stronger contrast, and coloured format headers choose a readable foreground. Copy feedback adapts to your appearance and text size without blocking controls.

Practical text cleanup

Remove duplicate or empty lines, trim whitespace on each line, collapse repeated spaces and normalize line endings. Find these under Text Cleansing or search the scratchpad for cleanup. Add the same steps to a flow, use them in Shortcuts and macOS Services, or run them from the CLI.

Mac menu bar picker

Open Text Case from the menu bar or press Control–Option–Command–T. Search for a saved flow or any standard format, move with the arrow keys and press Return to transform copied text. Restore the previous clipboard from the picker if you haven't copied something else since. Change the shortcut in Menu Bar settings.

On Mac, the Flows list uses compact rows with colour accents and shows the drop position when reordering. The menu bar picker shows step counts for flows and your active shortcut.

Command–Comma opens Settings on Mac. Launch Menu Bar opens the picker, and the format and template lists have more space between rows.

The Flow Storage button and its menu chevron stay readable in dark mode on Mac.

Launch Menu Bar and the global shortcut open the picker beneath the Text Case menu bar icon.

The menu bar picker stays within the visible display so the search field remains accessible.

Turn on Show All Formats in Menu Bar settings to browse standard formats before typing a search.

AI Transform

Open the sparkles button in Scratchpad, enter an instruction, and choose Generate. The text is processed on your device using Apple Intelligence. Review the result before choosing Copy Result or Use as Input. Undo restores the previous Scratchpad input. The model requires a supported device with Apple Intelligence ready. Generated text can vary, and very long requests may need shorter input.

In a flow, open Add Format → AI Formats → New AI Format. Give it a name and write the fixed prompt. Use that named format in any flow on this device. Each flow saves a copy of the prompt, so editing or removing a preset leaves existing steps as they were. Tap an AI step in the flow builder to edit its copy. Use Run AI Preview in the builder or Run AI Flow in the flow’s detail screen to generate a result.

The preset list is local. Saved flow steps carry their prompts with the flow in iCloud and in flow exports. Update Text Case on your other devices before syncing or importing flows with AI steps. Run AI flows in the main app. The menu bar, Share Extension and legacy Shortcuts cannot run enabled AI steps.

System requirements

2026.1 requires iOS or iPadOS 26.0 or macOS 26.0. AI needs supported hardware with Apple Intelligence enabled and the system model available.
