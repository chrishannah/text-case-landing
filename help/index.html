Help with Text Case

Get started with Scratchpad, import a flow, or get help if a transformation doesn’t work.

Start with an example

Open Scratchpad and choose Try an Example. Search for a format and preview its result. Copy it, or choose Use as Input to run another edit on that result. To build your own flow, start with Flows → Templates → Clean a List.

Set up the Mac menu bar picker

Open Text Case Settings and choose Launch Menu Bar. Use the Text Case menu bar icon or Control–Option–Command–T. Change that shortcut and choose what the picker shows in Menu Bar settings. Restore Clipboard is available while the clipboard still contains the last transformation result.

Using Text Case from other apps

On iPhone and iPad, look for Convert Text in the share sheet. On Mac, supported formats are available through Services. You can also use supported transforms and flows in Shortcuts. Run AI flows in the main app.

Frequently asked questions

How do I import or back up flows?

Open a .textcaseflow file from Files or Finder and confirm Import in Text Case. You can also drop the file onto the Flows list or choose Flows → Flow Storage → Import Flows. It imports as an editable copy. Choose Back Up All Flows to export your collection, or export one flow from its context menu.

My flows didn’t load. What can I do?

In Flow Storage, open Storage Status. Check iCloud Drive if you use it, then choose Retry Loading. Keep any exports you already have. If that doesn’t help, send support the storage status before restoring a backup.

Why is AI Transform unavailable?

It requires a supported device with Apple Intelligence enabled and the system model available. Try a shorter input if generation reports a length limit. Standard formats are available independently.

What happens when I share an AI flow?

The prompt is saved with the flow, including in its export. Review the prompt before sharing. Update Text Case on your other devices before syncing AI flows through iCloud.

Which systems does 2026.1 support?

iOS and iPadOS 26.0 or later and macOS 26.0 or later. Check your platform listing for current pricing and availability.
