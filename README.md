# Text Case website

Static site for textcase.app. Serve the repository root with any static HTTP host. There is no frontend build or dependency install.

```sh
python3 -m http.server 8080
```

The homepage has the App Store links, features, starter flow downloads and screenshots. The /features/, /release-notes/, /press/ and /help/ pages are standalone HTML. Update them and the sitemap when adding release content. All canonical and social URLs target textcase.app.

For future updates, export the starter flows from Text Case, update the press ZIP in downloads/, and use app captures without personal text. Keep the gallery, release notes and App Store links current with each release.
